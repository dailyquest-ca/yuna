# WO-A6 — replace the calendar with a condition, pre-registered

**Written before any cell in it runs.**

## Why

The phase test killed WO-A5's champion: the same semi-annual rule started one month later returns
23.44% instead of 32.07%, and started in June returns 14.45%. Seventeen points of spread from an
arbitrary date. Zak's objection was the correct one — *"we are relying on TIME to tell us when to
go back in? And not an observation of the market?"*

The churn analysis found what the calendar was standing in for. On the monthly clock the book
re-bought a name within 45 days of stopping OUT of it at a loss **213 times**, averaging 13.5 days
out of the name, and **111 of those 213 lost again**. The calendar's only real function was to
stop the book re-buying names that had just failed — and a slow calendar does that badly and by
accident, which is exactly why shifting it by a month changes everything.

`docs/yuna_plan.md` §3.2 already legislates the rule this arm never had:

> *"A stop-out carries no cooldown — re-entry requires a valid base and all gates, nothing more."*

## The entry door

**A name enters when its close makes a new 252-session high.** Nothing else changes: same 12-1 ÷
volatility rank, same top-500 pool, same §3.2 trail, same next-open fills, same SPMO park.

Why this door and not another:

- it is **an observation of the market**, which is the whole point
- it is §3.2's own entry in its simplest form — the plan enters on a break above a pivot, and a
  252-day high is a pivot with the base detection removed
- it was already built and measured in the E-series (A2's `entry_new_high=252`), so it is not a
  new invention chosen to fit
- it solves the churn directly and without a cooldown constant: **a stopped-out name cannot be
  re-bought until it has climbed back to a new one-year high**, which is what "requires a valid
  base" means operationally

No calendar exists in this arm at all. Every session, if a slot is free, the highest-ranked
qualifying name takes it. Names leave only via the trail.

## The reading, fixed now

An event-driven rule has no calendar phase to shift, so the analogous robustness test is the
**start offset**: begin trading one, two, three or four months later and the book you first own is
different, which is the same kind of arbitrary choice the phase test exposed.

- **Real** — the spread across `evt_hi8_s0..s4` is **under 5 CAGR points**. The calendar rule
  spread 17.6. A rule that is genuinely responding to the market should barely notice when you
  started watching.
- **Not real** — the spread is comparable to the calendar's. In that case the concentrated arm has
  no edge that survives an arbitrary choice, and the correct answer is SPMO.
- **Anything between** is reported as-is with the number, not narrated into a win.

Second bar, from §2.4.1: the arm must beat the park it is made of. **SPMO returned 21.12%** on
this window. The *mean across start offsets* — not the best one — is what gets compared to it.

## What is NOT in this work order

- **No displacement rule.** If the book is full and a better name qualifies, nothing happens. That
  is a second axis and adding it now would confound the one question being asked.
- **No cooldown constant.** The new-high door already prevents the churn; a tuned "wait N days"
  would be an invented value with no source in the plan.
- **No new pool, clock, band or overlay.** Everything else is held at WO-A5's measured settings.
- **No promotion on a single good cell.** 63 trials are already in the deflation ledger and these
  add more; a cell that beats the champion still has to clear the phase-analogue test above.
