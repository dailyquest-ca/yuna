## What the build taught us, beyond the previous handoff

**Vendor**
1. `General.CurrencyCode` and `CountryISO` both lie for depositary receipts — TSM reads USD/US
   and files in TWD. `Financials.*.currency_symbol` and `General.PrimaryTicker` tell the truth.
   EODHD's own `PriceSalesTTM` divides a USD market cap by TWD revenue, so its valuation ratios
   cannot cross-check this either.
2. A fundamentals request bills 10 units. Three sweeps of L0 is 84k of the 100k daily budget —
   plan the sweep before spending it, not after.
3. Ten concurrent workers draws occasional 429s; eight does not.

**Postgres**
4. A view defined `select *` freezes its column list at creation. Any migration adding a column
   to `fundamentals` must recreate `v_fundamentals_latest` in the same file.
5. `%s is false` inside a batch statement failed silently, flush fell back to row-by-row, and
   the fallback skipped a per-row step — so a whole column came back null and a bad name sailed
   through. Batch fallbacks must be recorded in the heartbeat, never just printed.

**The formulas, as implemented**
6. §3.3's data-confidence rule renormalizes around *one* missing component. Size is available to
   almost everything, so without a floor a company whose engine and cash conversion are both
   unmeasurable scores on smallness alone — a $4 ethanol microcap topped the first bench. Two
   components minimum, at least one a business measure.
7. The §3.1 engine reliability check is the load-bearing part of the hurdle. Growth dominates
   the expected-return formula, so a tolerance of 10pp is far too loose: it let a 7% grower
   underwrite at 16%. Now 5pp, and it lives in `score.py` where changing it costs no API calls.
8. **Reinvestment comes out at zero for asset-light compounders.** ANET, AVGO and VRT all show
   `reinvest_rate = 0` because working capital released more cash than capex consumed, and the
   plan floors reinvestment at 0 — so the engine is 0 for a company growing 27% a year. The
   implementation is faithful to §3.1; the consequence is that the CCN systematically ranks
   negative-working-capital compounders at the bottom. **This wants a plan decision, not a code
   change** — §3.1 is FINAL and the freeze protocol applies.
9. Everything the hurdle surfaces is a de-rated former high-multiple name, because `fair` is the
   stock's own median P/FCF and the drag is never a credit. That is the design, working. It also
   means the buyable list will always look like a fallen-growth screen.

**Health**
10. An amber must mark its own domain stale, not the whole machine. Two ways this nearly bricked
    trading: 30 permanently unscorable shells (SPACs, preferreds) held the pipeline amber
    forever, and the freshness gate treated any amber as blocking — so a Friday debugging
    session would have stopped Monday's orders. Only the price feed gates tickets now.
11. Freshness must read the *latest* run per job, not every run in the window.
